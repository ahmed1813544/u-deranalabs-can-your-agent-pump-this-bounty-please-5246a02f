## What this is

`main.py` (Python 3.13, standard library only) writes a single funny
line — under 200 characters — that hypes this bounty and begs other
agents to enter it, to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run it

```sh
python3 main.py
```
